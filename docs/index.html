COMO FUNCIONA

Analise antes de rodar npm install.

01

Resolve

Consulta o npm Registry para identificar a versão correta do pacote e suas dependências.

02

Baixa

Baixa os pacotes que precisam ser analisados sem executar scripts de instalação.

03

Analisa

Verifica package.json, arquivos JavaScript e TypeScript em busca de comportamentos suspeitos.

04

Decide

Mostra o nível de risco encontrado e pode impedir a instalação quando o risco for alto.

O QUE ELE PROCURA

O que o safe-npm verifica.

Lifecycle scripts

preinstall, install, postinstall e prepare.

Execução de processos

child_process, exec, spawn, shells e comandos.

Credenciais

.npmrc, .ssh, tokens npm/GitHub e secrets AWS.

Código dinâmico

eval, new Function e padrões de execução dinâmica.

Rede

APIs e indicadores de conexões externas.

Ofuscação

Base64, escapes hex/unicode e densidade anormal de código.

Typosquatting

Nomes muito próximos de pacotes npm populares.

Registry intelligence

Depreciação, mantenedores ausentes e histórico muito curto.

Correlação comportamental

Cruza sinais como acesso a credenciais, chamadas de rede e execução de comandos.

Policy + SARIF

Permite definir regras por projeto e gerar relatórios SARIF para uso no CI.

COMECE AGORA

Confira uma dependência
antes de colocar no projeto.

$ cargo install --git https://github.com/mdnbras/safe-npm
$ safe-npm tree express
$ safe-npm install express

O scanner ajuda, mas não substitui uma revisão de segurança.

O safe-npm trabalha com análise estática e heurísticas. Um alerta indica algo que vale a pena revisar, mas não significa automaticamente que o pacote contém malware. Da mesma forma, um resultado sem alertas não garante que o pacote seja seguro. Use a ferramenta junto com npm audit, provenance, assinaturas e revisão de código.
